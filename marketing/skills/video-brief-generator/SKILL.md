# video-brief-generator

Превращение утверждённых идей контент-плана в производственные брифы для видео-генератора.

## Когда запускать

Только после того, как идеи утверждены пользователем в `marketing/content-plans/` (статус "Утверждено"). Не генерировать брифы по идеям, которые ещё не утверждены.

## Вход

- Утверждённые идеи из последнего файла `marketing/content-plans/`.
- Провайдер видео-ИИ, зафиксированный в `marketing/CLAUDE.md` ("Текущий выбор провайдера"). Если провайдер не выбран — спросить пользователя, прежде чем продолжать.

## Что собрать для каждой идеи

- **Сцены**: покадрово — что в кадре, композиция, движение камеры
- **Длительность**: каждой сцены и общая длительность ролика
- **Стиль**: визуальный стиль (свет, цветокор, темп, референсы по эстетике)
- **Референсы**: ссылки/описания похожих роликов для ориентира
- **Промт для видео-генератора**: готовый текстовый промт под выбранного провайдера (Runway/Kling/Veo/Pika — формат промта у них разный, писать под конкретный синтаксис провайдера)
- **Аудио**: трек/звук из отчёта трендов, если применимо
- **Текст на экране**: тайминги субтитров/оверлеев из контент-плана

## Формат файла

Сохранить в `marketing/video-briefs/YYYY-MM-DD-briefs.md`, один раздел на идею:

```markdown
# Видео-брифы — YYYY-MM-DD

## Бриф 1: [Название идеи, ссылка на идею из контент-плана]
- **Провайдер**: [Runway/Kling/Veo/Pika]
- **Длительность**: X сек
- **Сцены**:
  1. (0-Xс) ...
  2. (Xс-Yс) ...
- **Стиль**: ...
- **Референсы**: ...
- **Промт**: 
  ```
  [готовый промт под провайдера]
  ```
- **Аудио**: ...
- **Текст на экране**: ...
- **Статус**: черновик / отправлено в генерацию / готово / одобрено пользователем

...
```

## Обязательно

- Брифы — это только промты и инструкции, **не публикация**. Генерация видео через API провайдера — с ведома пользователя (стоимость по API-ключу).
- После генерации ролика статус меняется на "готово", но **публикация только после явного одобрения пользователем** (см. правило в `marketing/CLAUDE.md`).
