# posting-tracker

Учёт опубликованных роликов и их метрик.

## Когда запускать

- Сразу после публикации ролика (вручную пользователем или автопостингом по расписанию) — зафиксировать факт публикации.
- Раз в неделю — обновить метрики по роликам за последние ~1-2 недели и собрать сводку.
- По прямому запросу пользователя ("как отработал последний пост", "сводка за неделю").

## Что фиксировать при публикации

Добавить запись в `marketing/published/log.md`:

```markdown
## [Дата публикации] — [Название идеи]
- **Ссылка на пост**: ...
- **Бриф**: ссылка на marketing/video-briefs/...
- **Идея из плана**: ссылка на marketing/content-plans/...
- **Метрики (обновляется)**:
  - Просмотры: ...
  - Охват: ...
  - Лайки: ...
  - Комментарии: ...
  - Сохранения: ...
  - Дата замера: ...
```

Метрики брать из Instagram Insights (вручную от пользователя, или через API, если подключён Meta App с нужными правами — см. `marketing/CLAUDE.md`). Не пытаться скрапить метрики через неофициальные способы.

## Еженедельная сводка

Раз в неделю добавлять раздел в `marketing/published/log.md` или отдельный файл `marketing/published/YYYY-MM-DD-summary.md`:

```markdown
# Сводка за неделю — YYYY-MM-DD

## Топ по результатам
1. [Идея] — просмотры/охват/лайки, почему сработало (формат, хук, тайминг)
2. ...

## Слабые результаты
1. [Идея] — что не сработало, гипотеза почему

## Выводы для следующего контент-плана
- ...
- ...
```

## Обязательно

- Эта сводка — вход для следующего запуска `content-calendar`: явно упоминать, какие форматы повторять, какие не использовать.
- Не делать выводов на основе 1-2 постов — если данных мало, так и написать в сводке ("недостаточно данных, нужно больше публикаций для выводов").
