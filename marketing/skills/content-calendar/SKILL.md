# content-calendar

Сборка недельного контент-плана для Instagram Dukenim.

## Когда запускать

После того как готов свежий отчёт трендов (`marketing/trends/`), или по прямому запросу пользователя. Если свежего отчёта трендов нет (старше ~2 недель) — предложить сначала запустить `trend-research`.

## Вход

- Последний файл из `marketing/trends/`.
- Контекст продукта/тарифов Dukenim (уточнить у пользователя нишу и тон бренда, если ещё не зафиксированы в `marketing/CLAUDE.md`).
- Прошлые сводки метрик из `marketing/published/`, если есть — учитывать, что уже сработало/не сработало.

## Что собрать

10-14 идей роликов на неделю. Для каждой идеи:

- **Хук** (первые 1-3 сек, что удерживает внимание)
- **Сценарий**: 3-5 сцен, коротко что происходит в каждой
- **Текст на экране** (субтитры/оверлеи по сценам)
- **CTA** (что должен сделать зритель — подписаться, написать в директ, перейти по ссылке и т.д.)
- **Формат-референс**: на какой тренд из отчёта опирается идея (или "оригинальная идея", если не привязана к тренду)
- **Цель**: охват / вовлечение / заявки / узнаваемость бренда

## Формат файла

Сохранить в `marketing/content-plans/YYYY-MM-DD-plan.md`:

```markdown
# Контент-план на неделю — YYYY-MM-DD

## Идея 1: [Короткое название]
- **Хук**: ...
- **Сценарий**:
  1. ...
  2. ...
  3. ...
- **Текст на экране**: ...
- **CTA**: ...
- **Референс тренда**: ...
- **Цель**: ...

... (10-14 идей)

## Статус
Ожидает утверждения пользователем.
```

## Обязательно

- **Никогда не передавать план в `video-brief-generator` без явного утверждения пользователя.** После сборки — показать план и спросить, какие идеи утверждены (все / часть / нужны правки).
- Отмечать в файле статус: "Ожидает утверждения" → после ответа пользователя обновить на "Утверждено (идеи: 1,3,5...)" или "Утверждено с правками".
