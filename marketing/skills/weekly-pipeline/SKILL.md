# weekly-pipeline

Автоматический еженедельный агент. Делает всю бесплатную/текстовую часть работы сам (сбор трендов, план, сценарии), и останавливается перед любым шагом, который стоит денег или публикует что-то наружу.

## Что входит в автоматический прогон (без вопросов пользователю)

Выполнять по порядку, один за другим, в рамках одного запуска:

1. **trend-research** — собрать актуальные тренды (веб-поиск + обычный просмотр Instagram/TikTok в браузере). Сохранить отчёт в `marketing/trends/`.
2. **content-calendar** — на основе свежих трендов и сводки из `marketing/published/` (если есть) собрать план на неделю: 10-14 идей под Instagram Reels, часть из которых явно помечена как «легко адаптируется под TikTok» (те же сцены, вертикальное видео, без привязки к Instagram-специфике типа "смотрите наши истории"). Сохранить в `marketing/content-plans/`.
3. **video-brief-generator** — сразу, без ожидания отдельного одобрения по каждой идее, написать сценарии/брифы для ВСЕХ идей из плана (это текст — бесплатно). Для каждого сценария указать явно: подходит ли для кросспостинга в TikTok "как есть" или нужна адаптация (например, TikTok — более сырой/нативный монтаж, Instagram Reels — более отполированный). Сохранить в `marketing/video-briefs/`.

## Что НЕ входит — требует отдельного явного одобрения пользователя

- Генерация самого видео через Kling API (это платно — см. `marketing/CLAUDE.md`, раздел "Видео-генерация")
- Публикация в Instagram или TikTok (это необратимо и публично)
- Автопостинг по расписанию — разрешён только для уже одобренных материалов (см. `marketing/CLAUDE.md`, раздел "Проверка человеком")

## Формат сдачи пользователю

После прогона всех трёх шагов — одно сообщение с:
- Итогом недели (сколько идей, на какие тренды опираются, что нового по сравнению с прошлой неделей)
- Ссылками на все три файла (тренды, план, сценарии)
- Явным списком того, что дальше требует его решения: какие сценарии отдавать в генерацию видео (Kling), и когда публиковать

Ничего дальше этого пакета не делать, пока пользователь не отметит, какие сценарии одобрены.

## Если данных для триггера нет

Если за неделю не было публикаций для сводки в `marketing/published/` — это нормально, просто не включать блок "что сработало на прошлой неделе" в контент-план и не блокировать прогон.
