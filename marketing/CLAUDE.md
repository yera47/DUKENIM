# Dukenim Marketing — правила проекта

Это **отдельный проект** от разработки приложения Dukenim. Разработку ведёт Codex в другом проекте.
Здесь агент занимается **только маркетингом и продвижением в Instagram**: тренды → контент-план → видео-брифы → публикация → аналитика.

## Жёсткое правило масштаба

- **Не трогать код продукта** (всё, что вне папки `marketing/`), не давать советы по разработке, архитектуре, базе данных и т.д.
- Если просят что-то про код приложения — отвечать, что это зона Codex, и не браться за это здесь.
- Вся работа этого проекта живёт внутри `marketing/`.

## Структура

- `trends/` — разборы актуальных трендов (форматы, звуки, мемы), результат работы скилла `trend-research`.
- `content-plans/` — контент-планы на неделю, на утверждение пользователю, результат работы скилла `content-calendar`.
- `video-briefs/` — брифы для видео-генерации по утверждённым идеям, результат работы скилла `video-brief-generator`.
- `published/` — лог опубликованного + метрики, результат работы скилла `posting-tracker`.
- `skills/` — сами скиллы (описаны ниже).

## Скиллы

1. **trend-research** — раз в неделю ищет актуальные форматы/звуки/мемы в нише через веб-поиск и обычный просмотр Instagram/TikTok в браузере (без автоматизированного скрапинга через неофициальные API — это нарушает ToS Meta и грозит баном аккаунта). Результат — короткий отчёт в `trends/`.
2. **content-calendar** — на основе трендов собирает план на неделю (10-14 идей: хук, сценарий на 3-5 сцен, текст на экране, CTA) под тарифы/продукт Dukenim. Отдаётся пользователю на утверждение **до** производства — в `content-plans/`.
3. **video-brief-generator** — превращает утверждённые идеи в брифы для видео-ИИ (сцены, длительность, стиль, референсы) — готовые промты для внешнего видео-генератора. Сохраняется в `video-briefs/`.
4. **posting-tracker** — после публикации фиксирует метрики (просмотры/охваты/лайки) и раз в неделю делает сводку: что сработало, что нет — чтобы следующий контент-план это учитывал. Ведётся в `published/`.
5. **weekly-pipeline** — раз в неделю автоматически прогоняет trend-research → content-calendar → video-brief-generator одним пакетом (без запроса подтверждения на каждом шаге, т.к. это только текст/сценарии — бесплатно) и отдаёт всё разом на одно общее утверждение пользователю. Генерация видео (Kling, платно) и публикация — отдельные шаги, только по явному "да" пользователя.

## Площадки

Instagram — основная площадка. TikTok — видео переиспользуется (то же Reels-видео с минимальной адаптацией под TikTok-нативность). Threads/X — пока не подключены.

## Публикация в Instagram — что нужно от пользователя

Автоматическая публикация через API невозможна без:
- Instagram Business или Creator аккаунт, подключённый к Facebook-странице.
- Meta App (developers.facebook.com) с разрешением `instagram_content_publish` и долгоживущим access token.
- Instagram Business Account ID.

Без этого — только черновики видео и ручные планы. Не пытаться публиковать напрямую в обход этого.

## Видео-генерация

Используется **один** провайдер видео-ИИ за раз (Runway / Kling / Veo / Pika — выбор фиксируется здесь после решения пользователя). Не переключаться между несколькими провайдерами без необходимости. Перед масштабированием — протестировать на 5-10 брифах и посчитать реальную стоимость ролика.

**Текущий выбор провайдера:** Kling (выбран как самый дешёвый из рабочих API — ~$0.18-0.31 за 5-секундный ролик). Перед масштабированием — протестировать на 5-10 брифах и посчитать реальную стоимость. При необходимости пересмотреть.

## Проверка человеком — обязательна

Ни один ролик не публикуется автоматически без явного одобрения пользователя. Автопостинг разрешён **только** для уже одобренных материалов по расписанию. Никогда не публиковать в обход этого шага, даже если пользователь торопит.

## Статус доступа к Meta API

Ничего не настроено (проверено 2026-08-11): нет данных о Business/Creator аккаунте, Meta App не создан, токена и Instagram Business Account ID нет. Публикация в Instagram — только вручную пользователем, автопостинг через API недоступен, пока это не будет настроено.
